# HomeFinder — Prime European Real Estate Marketplace

HomeFinder is a modern, production-style real estate marketplace web application tailored for discerning buyers, investors, property owners, and certified real estate brokers across Central Europe's historic capitals (Budapest, Vienna, Amsterdam, Prague, and Warsaw).

## 🚀 Key Features Implemented

1. **Home Page**:
   - Immersive hero section with multi-parameter search bar (Buy/Rent, European Capital, Property Architecture Type, Max Budget, Bedrooms).
   - Curated Featured Residences with high-resolution imagery and key property specifications.
   - Geographic Capital Explorer (Budapest, Vienna, Amsterdam, Prague, Warsaw).
   - Market-fresh recently added properties.
   - "Why choose us?" value propositions (Legal title audits, certified local brokers, concierge viewings).
   - Call-to-action banners for property owners and accredited agents.

2. **Property Search & Discovery**:
   - Advanced filtering sidebar (Transaction type, city, property type, price slider, bed/bath counters, area slider, parking, furnishing status).
   - Live text search across titles, districts, and streets.
   - Interactive Simulated Map visualizer with clickable pin markers and quick property preview popups.
   - Grid View vs. List View toggle.
   - Multi-option sorting (Newest, Price Low-High, Price High-Low, Area Largest).
   - Responsive mobile filter modal drawer.

3. **Property Details Page**:
   - Full-width image gallery with thumbnail navigator, fullscreen lightbox modal, and image counters.
   - Key specifications bar (Bedrooms, Bathrooms, Floor Area, Energy Rating Class).
   - Architectural narrative, construction year, and parking metadata.
   - Amenities grid with verified icons.
   - Interactive Architectural Floor Plan viewer (Multi-level tabs).
   - Neighborhood & Surroundings map with proximity highlights (Transit, Schools, Dining).
   - Certified Broker profile card and direct inquiry form.
   - Interactive Schedule Viewing appointment modal with real-time slot selection.
   - Contextual Similar Properties recommendations.

4. **Favorites & Side-by-Side Comparison Matrix**:
   - Saved personal portfolio with one-click toggles and local persistence.
   - Comprehensive Side-by-Side Comparison Table evaluating up to 4 properties simultaneously across price, price per square meter, energy efficiency, parking, and amenities.

5. **Agent Directory & Profile Pages**:
   - Certified European broker directory with city filters and language search.
   - Detailed agent profile with credentials, spoken languages, direct phone, and email.
   - Dedicated active listings portfolio per agent.
   - Direct message modal.

6. **List Your Property (Multi-Step Submission)**:
   - 5-step guided wizard + live marketplace card preview before publishing.
   - Curated architectural photograph presets or custom URL inputs with instant thumbnail previews.
   - Direct addition to local application state and immediate marketplace availability.

7. **User Dashboard**:
   - Saved properties shortlist.
   - Recently viewed listings history.
   - Inquiries log tracking agent replies.
   - Scheduled private viewings tracker with cancellation management.
   - Profile and notification preferences manager.

8. **Admin Operations Console**:
   - Executive statistics cards (Portfolio volume, active listings, inquiry rate, private bookings).
   - Complete property inventory table with homepage "Featured" toggles and deletion controls.
   - Legal Title & Compliance verification queue (Approve / Reject incoming listings).
   - Inquiry Dispatch console with status updates (New / Replied / Viewing Booked).
   - Accredited broker management & registration modal.
   - Platform user management.

## 🛠️ Technology Stack

- **React 18** + **TypeScript**
- **Tailwind CSS**
- **Lucide React** (modern iconography)
- **Local Storage Layer** for robust persistence without requiring an external backend

## 💻 How to Run the Project Locally

```bash
# 1. Install dependencies
npm install

# 2. Start the development server (runs on port 3000)
npm run dev

# 3. Build for production
npm run build
```
